# rigorix-schemas

The canonical Rigorix contracts — **JSON Schemas + conformance fixtures** — as
a versioned, consumable crate. This is the distributable form of the
repo-root [`schemas/`](../schemas) corpus (strategy freeze **D-1/D-2**): one
copy, consumed by `rigorix-verifier`, the Python/TypeScript verifiers, and both
servers — no vendoring, no drift.

The crate is **data + lookup**:

- **No `rigorix-engine` dependency** (D-1).
- **No runtime filesystem access** — the corpus is embedded at build time.
- No runtime dependencies (the `$id` map is generated by `build.rs`).

## API

```rust
use rigorix_schemas::{fixture, schema, schema_by_id, schema_names};

let envelope = schema("envelope.json").expect("envelope schema");
let catalog  = schema("api/catalog.json").expect("catalog");
let chain    = fixture("integrity/chain.json").expect("ADR-016 chain fixture");

// Resolve an `$id` for cross-file `$ref` registration.
assert_eq!(
    schema_by_id("https://rigorix.eu/schemas/envelope-v2.json"),
    Some("envelope.json"),
);

// Every embedded path (schemas AND fixtures), sorted.
for path in schema_names() {
    let _ = schema(path);
}
```

| Function | Purpose |
|---|---|
| `schema(rel_path)` | Embedded contract/fixture by path relative to `schemas/`. |
| `schema_names()` | Every embedded path, sorted. |
| `fixture(rel_path)` | Shorthand for `schema("fixtures/" + rel_path)`. |
| `schema_by_id(id)` / `schema_ids()` | The `$id -> path` map. |
| `FILES` | The raw `(path, contents)` table (generated). |

## How embedding works

`schemas/` inside this crate is a **symlink** to the repo-root `schemas/` (the
single source of truth). `build.rs` walks it and writes an `include_str!` table
into `$OUT_DIR`, so:

- in the repo, the symlink resolves to the canonical corpus;
- `cargo package` **dereferences** the symlink into the published crate, so the
  packaged crate builds standalone with no path/env dependency on the repo.

No duplicate copy is committed anywhere.

A sync test (`embedded_corpus_matches_disk`) walks the on-disk corpus and fails
if the embedded set diverges — the two can never silently disagree.
