## The gap (verified 2026-10-18)

`rigorix-oss` `engine/src/audit/domain/envelope.rs`:

```rust
pub enum HistoryIntegrity { LocalUnanchored, Anchored, AnchoredPending }
```

`envelope_factory_impl.rs:137,359` emits `AnchoredPending` with `anchor_head: None`
when anchored mode is configured but no head has been verified (startup window).
With `rename_all = "snake_case"` that is `"anchored_pending"`, which
`schemas/envelope.json` rejected. The SDK verifier's frozen enum copy was also
missing the variant.
