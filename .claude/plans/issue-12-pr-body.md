## Summary

Freezes the **contract half of ADR-016** (audit integrity) in rigorix-sdk before
the servers implement it — the same freeze-before-build discipline as the
`rigorix.*` catalog and the SSE push channel. The engine's ADR-016 **Phase A**
landed (`rigorix-oss` #902, `83e904ad`), so the envelope chain fields are now code
truth. This PR makes `schemas/envelope.json` + the three anchor artifacts describe
and check them, and teaches the independent verifier to verify a per-producer
chain and accept a gap only when a signed compaction checkpoint covers it.

Closes #12.

## Changes

**`schemas/envelope.json`** — additive, serde-defaulted, in engine struct order
(after `evidence_degraded`, before `approval_events`):
`producer_id` / `sequence` / `prev_hash` / `history_integrity`
(`local_unanchored` | `anchored`) / **`history_policy`** (`allow_unanchored`) +
`$defs.historyIntegrity` / `$defs.historyPolicy`.

**New FROZEN anchor-artifact schemas**
- `schemas/api/ledger-receipt.json` — `{ ledger_id, envelope_hash, sequence, recorded_at, sig }`
- `schemas/api/history-slice.json` — `{ scope, since, actions[], head_hash, sig }`
  (actions mirror the engine `HistoryAction`; no parameter values)
- `schemas/api/compaction-checkpoint.json` — `{ sequence_from, sequence_to, reason, prior_head, new_head, sig }`

Each documents its `x-signing` form: **Ed25519** over the compact JSON with `sig`
set to null.

**`schemas/fixtures/integrity/`**
- `chain.json` + `broken-chain.json` — **engine-produced** (real
  `AuditEnvelopeFactoryImpl` runs, key `fixture-hmac-key-2026`, sequences `0..2`;
  the broken one deletes the middle envelope).
- `ledger-receipt.json` / `history-slice.json` / `compaction-checkpoint.json` —
  Ed25519 contract fixtures (documented test-only key; regenerated by an ignored
  generator test). The checkpoint covers the broken chain's `1..=1` gap.

**`rust/rigorix-verifier`**
- Frozen structs gain the chain fields, `HistoryIntegrity` / `HistoryPolicy`, and
  the previously-missing `requirement_findings` (now mirrors the engine struct
  field-for-field → canonicalization parity).
- `envelope_hash` — SHA-256 over the **same canonical bytes** the HMAC signs
  (`signature` nulled): one canonical form for HMAC / `prev_hash` / ledger
  `envelope_hash` / checkpoint heads.
- `verify_chain` — genesis 0 + contiguous sequence + `prev_hash` continuity;
  legacy (unchained) envelopes grandfathered.
- `verify_chain_with_checkpoints` — accepts a gap **iff** a valid Ed25519-signed
  checkpoint brackets it (`prior_head == hash(before)`, `new_head == prev_hash(after)`,
  exact range); an uncovered gap fails.
- `verify_{ledger_receipt,history_slice,compaction_checkpoint}` — Ed25519
  (`ed25519-dalek`).

**Docs** — `schemas/README.md`, `schemas/api/README.md`,
`schemas/fixtures/integrity/README.md`, and an ADR-016 delta note in
`docs/contract-sync-2026-09-06.md`.

## Drift found and fixed (code is truth)

- Issue #12 named four envelope fields; the engine also adds **`history_policy`**
  (`HistoryPolicy::AllowUnanchored`, the recorded opt-in that makes the
  unanchored regime auditable). Added.
- The verifier's frozen `AuditEnvelope` was missing `requirement_findings`
  (ADR-015); it now mirrors the engine struct field-for-field.
