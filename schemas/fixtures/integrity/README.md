# `schemas/fixtures/integrity/` — ADR-016 audit-integrity fixtures

Fixtures for the audit-integrity contract (ADR-016 / SDK-AUDIT-A, issue #12).
Two families:

## Envelope chain (engine-produced)

| Fixture | What |
|---|---|
| `chain.json` | Three **real rigorix-oss engine-signed** envelopes (ADR-016 Phase A, #902), producer `local`, sequences `0,1,2`, contiguous `prev_hash` links, all tagged `history_integrity = local_unanchored`. |
| `broken-chain.json` | The same run with the **middle envelope deleted** (sequences `0,2`) — an uncovered interior gap. `verify_chain` rejects it; a valid signed checkpoint accepts it. |

Produced by the engine's `AuditEnvelopeFactoryImpl` with the fixed test-only key
`fixture-hmac-key-2026` (the same key as `../envelope/`). Regeneration requires
building the engine and walking `next_link_from` + `build_envelope` — the chain
fixtures are **not** regenerated by the SDK.

## Anchor artifacts (contract fixtures, no anchor implementation yet)

| Fixture | Schema | What |
|---|---|---|
| `ledger-receipt.json` | `api/ledger-receipt.json` | The anchor's signed acknowledgement of the chain head. |
| `history-slice.json` | `api/history-slice.json` | The signed history projection the guard consumes in `anchored` mode. |
| `compaction-checkpoint.json` | `api/compaction-checkpoint.json` | Covers the erased range `1..=1` of `broken-chain.json` (GDPR erasure); its `new_head` is the link the surviving successor stores. |

These are **TEST-ONLY** Ed25519-signed with the deterministic seed
`[7u8; 32]`; public key (hex):

```
ea4a6c63e29c520abef5507b132ec5f9954776aebebe7b92421eea691446d22c
```

Canonical signing form (documented per schema): Ed25519 over the compact JSON of
the artifact with `sig` set to **null** — UTF-8 bytes, declaration field order.
The HMAC envelope form and the anchor form are distinct only in the signing
primitive; the envelope's `prev_hash`/`envelope_hash` still use the HMAC
canonical bytes.

Regenerate the anchor fixtures (not the chain) with:

```bash
cd rust
cargo test -p rigorix-verifier generate_anchor_fixtures -- --ignored
```

The gate is:

```bash
cd rust
cargo test -p rigorix-verifier integrity_   # chain + anchor fixture tests
```
